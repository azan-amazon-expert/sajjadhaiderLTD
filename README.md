# SajjadHaiderLtd Website

## Run locally
1. Open this folder in VS Code.
2. Open Terminal.
3. Run `npm install`
4. Run `npm run dev`
5. Open the local URL shown by Vite.

## Build
`npm run build`

## Pages
- `/` Home
- `/shop` Shop All (all 56 Etsy products)
- `/about` About
- `/faq` FAQs

The original uploaded HTML was used as the source for the 56 Etsy product titles, prices, listing URLs and images, and the embedded SajjadHaiderLtd logo was retained for the header/footer and favicon.


## Favicon update
The supplied black-and-white SH house mark is used for browser favicon and app icons. The existing SajjadHaiderLtd header/footer logo file (`public/sajjadhaiderltd-logo.png`) is unchanged.
